01

64-Byte Cache Lines

CPUs never fetch a single integer from RAM. Every cache miss transfers an entire aligned 64-byte block (4 slots here) across the memory bus, paying the same ~100-cycle DRAM latency regardless of how many slots are actually useful.

02

Spatial Locality in Arrays

Array elements sit back-to-back in RAM. One cache miss on arr[0] pulls arr[0..3] into L1 Cache at once—yielding 3 consecutive 4-cycle L1 hits immediately afterward (75% hit rate even without prefetching).

03

Pointer Chasing & Thrashing

Heap-allocated Linked List nodes are scattered across random RAM addresses. Each 64B fetch brings 75% unrelated heap bytes, evicts older L1 lines (LRU thrashing), and forces a fresh 100-cycle CPU stall on virtually every node.

04

Hardware Prefetching (MLP)

Modern cores detect sequential array strides (+0x40) and overlap future RAM fetches in parallel so cache lines arrive before needed. Pointer chasing creates a strict data dependency (n = n->next), leaving the prefetcher blind.
